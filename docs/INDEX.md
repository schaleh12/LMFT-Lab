# GFT-Lab documentation

This area is for research specifications, architecture documents, hypotheses,
and theoretical design. No GFT theory or implementation architecture is defined
by this index.

## Established project decisions

- [AGENTS.md](../AGENTS.md) defines the repository's research and development rules.
- [README.md](../README.md) describes the project goals, environment, and layout.
- GFT decision-making must remain conceptually separate from LLM reasoning.
- Simplicity, inspectability, reproducibility, and scientific validity take priority.
- Python 3.12 is the current implementation environment.

## Open research questions

The concrete GFT representation, reasoning semantics, evolutionary operations,
and fitness definitions have not been established in this scaffold. This index
does not select answers or authorize implementation of these areas.

When research documents are added, link them here and clearly label established
decisions, proposed hypotheses, open questions, and supporting experimental
evidence. A hypothesis is not an established result, and a proposed design is
not an approved implementation decision. Treat theory and hypothesis documents
as research specifications; do not silently rewrite them while implementing code.
