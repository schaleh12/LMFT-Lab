it uses the new action eligibility filter, so cannot measure the original selector's

service and known availability metadata; the original algorithm ignores availability
and correction offers. No action-ranking score, production selector or thresholds change.

Gather replies are exact selected-coordinate authored records with true values;
original full-question requests may add corroborating records at already covered
parts. They append roots, never supersede contradictory originals or vote them away.

policy for choosing one. Ordinary memory retains full action-aware capabilities.
Thus full-versus-original compares the combined action adapter (type AND eligibility),
not an isolated seed effect; full-versus-filtered-gather contrasts correction access.
