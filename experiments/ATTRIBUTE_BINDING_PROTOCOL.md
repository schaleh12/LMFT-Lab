## Representation, evidence and worlds

Public observations are three neutral integer channels a,b,c, each in {0,1,2,3}.
The experimental representation is version neutral-binding-1. Enumerate all six
ordered DISTINCT operand pairs and operators lt,le,eq,ge,gt,ne:36 representations.
Group representations by their complete Boolean truth vector over the64 lexicographic
domain triples. Thus reversed equivalents are one behavioral class (18 expected),
with every member retained for audit. Class IDs are hashes of those public truth
vectors, never of world identities. Query votes count classes once, not representations.
The finite family is supplied experimentally; no runtime hypothesis repair is added.

The oracle alone binds length, capacity and a distractor to the channels using each
of the six permutations. Outcomes come from the existing capacity_fixture.execute
procedure. These permutations are symmetry checks, not six independent replications.
The learner receives only neutral observations, evidence labels, neutral identities,
synthetic verification receipts and public policy. No mapping, semantic field names,
world IDs, held-out labels or mapping-derived ordering enters learner requests/state.
Pairings of indistinguishable training histories must produce byte-identical public
requests/states/selection before informative evidence; a different hidden mapping
cannot change a choice without changing authorized observations.

Primary physical training triples (length,capacity,distractor) are
(0,0,0),(1,2,1),(2,1,2),(2,2,2). Distractor equals length, while equality examples
already distinguish strict from non-strict comparisons. Transform to channels, sort
lexicographically, and assign neutral t000.. IDs. Labels are produced by the oracle;
the learner never receives the physical triples or conversion. Already-supported
control uses every neutral triple in {0,1,2}^3 (27), labeled by the same oracle.

All controls share the same64-case public domain, family, tie ordering and budget.
The full query pool is every neutral triple in {0,1,2}^3, sorted lexicographically,
q000..q026. It is constructed without the mapping or any outcomes. Unavailable pool
is only the three diagonal triples. Candidate pool labels are never fetched for
selection; the oracle answers only a selected request. Pool membership is not evidence.
One lifetime query is charged at selection and remains spent even if replies reject.
No retry/reset/new episode. Exact retransmissions of admitted evidence are idempotent.

Held-out features are all neutral triples in {0,1,2,3}^3 with at least one coordinate3
(37). None can be training or query points. This frozen symmetric grid varies the
distractor, includes equality and both outcomes, and tests new numeric combinations.
Also report the equality subset (oracle length=capacity), success/failure subsets,
and predictions grouped by fixed length/capacity across available distractor values.
This is bounded finite-domain generalization, not arbitrary-range extrapolation.

## Conditions, phases and controls

For each permutation and implementation, evaluate:
1. informative: primary training; maximum predicted class disagreement over full pool;
2. no-acquisition: primary training; no query;
3. noninformative: primary training; first full-pool point with zero disagreement;
4. unavailable: primary training; maximum disagreement over diagonal-only pool;
5. already-supported:27 training points; maximum disagreement over full pool.

Disagreement score is true_votes * false_votes. Informative/unavailable/supported
request only when max score>0; ties choose first lexicographic pool point. Explicit
noninformative control can request a zero-score point (possibly repeating features
of a training event). These overrides are labeled, not improvements to the selector.
Empty sets never select or predict; no vacuous consensus. A Boolean observation need
not identify a unique class: retain every survivor if it does not. No tie default.

Training/admission filters hypotheses against admitted evidence only. Then freeze
pre-acquisition predictions and the selected request before obtaining its label.
Only that one admitted acquisition outcome may filter further. There is NO separate
validation phase in this isolated diagnostic; evaluation cannot accept/reject/filter
an ambiguous family. Read-only consensus predicts only when all nonempty survivors
agree, otherwise abstains with an explicit reason. Freeze all post-acquisition
predictions to disk before the evaluator accesses held-out outcomes. Evaluation
reports performance; it cannot write back into learner state. No production concept
admission or automatic deployment follows from this study.

## Independent comparator and causal controls

The primary experimental learner evaluates explicit relation representations and
records per-class evidence counterexamples. Ordinary memory independently computes
truth-table bitmasks using integer comparison signs, filters masks against observed
positive/negative rows, selects by table disagreement and predicts by table votes.
Neither path calls the other's evaluator, eliminator, query selector or predictor.
They share only the declared schema/candidate information, trusted admission boundary,
state lifecycle and storage primitives. Both get identical evidence/query opportunities,
budgets and persistence. Compare complete scientific outputs, not just final accuracy.
Frozen no-acquisition/noninformative/unavailable survivors isolate the effect of new
informative evidence. Already-supported cases prevent blanket abstention passing.
The fixed seed is not used as a decorative cause; this study has no propagation claim.

## Boundaries, persistence and falsifiability

Oracle verification lives in the coordinator, outside worker imports. Strict records
and separate trusted digest receipts admit only actually verified labels. Receipts
are synthetic local attestations, not authentication against a hostile process with
filesystem access. Invalid schemas, numeric Boolean aliases, unverified labels,
wrong scopes/phases, unrelated acquisitions, conflicting IDs and duplicates are
checked before learning. Evidence and rejection reasons retain provenance without
world identity. Empty-set behavior is tested using contradictory authorized diagnostic
records; these are a separate unit fixture, not fabricated primary oracle outcomes.

Use actual subprocesses: training/selection checkpoint; a new process loads pending
state and admits the reply; another loads evaluation state and predicts read-only.
Compare all stages with uninterrupted transitions. Persist evidence, survivors,
counterexamples, rejection reasons, selection and spent budget. Check exact hashes,
source/config pins, and prediction non-mutation. The actual worker request schema must
reject hidden mapping/labels; forbid oracle import in the worker. Pairwise identical
public training inputs across swapped length/distractor worlds provide a leakage test
at the real serialized boundary, not only a mock test.

Preregistered scientific questions: Does one selected observation separate operand
bindings, and does resulting consensus transfer under distractor variation? Report
actual survivor classes, coverage numerator/37, correct/decided, wrong and abstained
before/after for every permutation/control/implementation. Report remaining ambiguity
and zero coverage honestly; do not revise pools or criteria to force identification.
A bounded positive result requires correct transferable decisions after informative
evidence, invariant to distractor when identified, with uncertainty retained when not
identified and matched restart behavior. A competent baseline matching is expected
and is not an LMFT advantage. Failures under neutral relabeling or independent
distractors challenge binding/identifiability and block broader integration.
